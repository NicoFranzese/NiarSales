NIARSALES HQ - OFICINA 3D v3.1 - AJUSTES

Correcciones incluidas a partir de la captura del usuario:
- Carteles de Nico, Nora y Araceli ubicados dentro de sus oficinas ejecutivas.
- Coordinadora rotulada Nora (no Norma).
- Boxes operativos ubicados en el salon central, fuera de la sala de reuniones.
- Boxes abiertos con divisiones bajas y pasillo frontal libre.
- Ivo, Ada, Leo y Mia siempre representados: se usan los agentes reales si llegan desde API; si falta alguno se crea una representacion visual fallback.

- Mapu y Puchu recorren una trayectoria amplia por el mapa.

Instalacion: reemplazar los archivos del frontend incluidos y ejecutar npm start. No agrega dependencias.
Nota: no se pudo realizar build Angular en el entorno de preparacion porque npm install excedio el tiempo disponible.
